Build a clean, modern, mobile-friendly Drinking Water Delivery Agency Customer Portal.

Main Objective

Create a customer-only ordering website for a drinking water delivery agency. The website should be intentionally simple and focused on two primary functions:

Customers can place a drinking water order.
Customers can view their own order and delivery details.

Do not expose unnecessary business-management features to customers.

User Roles

There should be two types of access:

Customer

Customers can:

Register and log in.
View their profile and delivery address.
Place a new water order.
View their previous and current orders.
View the status of their delivery.
View delivery details such as expected delivery date/time, quantity, and address.
Cancel an order if the order has not yet been dispatched.
Contact the delivery agency.

Customers must only be able to see their own orders and information.

Admin / Agency Staff

Keep the administration area separate from the customer-facing ordering window.

Admin/staff should be able to:

Add and manage water products.
View incoming orders.
Update order status.
Assign deliveries.
Update delivery date/time.
Manage customer information.
View delivery addresses.
Mark orders as delivered or cancelled.

The admin dashboard must not be visible to normal customers.

Customer Home Page

Create a simple dashboard with:

Agency logo and name
"Order Water" button
"My Orders" button
"Current Delivery" section
Customer name
Saved delivery address
Contact/support button
Logout option

Keep the interface minimal and easy to use, especially on mobile phones.

Order Water Page

Create an easy order form containing:

Water product/type
Bottle/container size
Quantity
Price per unit
Total price
Delivery address
Preferred delivery date
Preferred delivery time slot
Optional order note

Example products:

20 Litre Water Jar
10 Litre Water Jar
5 Litre Water Bottle
1 Litre Water Bottle Pack

The product list and prices should be configurable by the admin.

When the customer clicks "Place Order", show an order confirmation containing:

Order ID
Ordered products
Quantity
Total amount
Delivery address
Expected delivery date
Delivery time slot
Order status
Order Status

Use clear visual status indicators:

Order Placed
Order Confirmed
Preparing
Out for Delivery
Delivered
Cancelled

Use different colors/icons for each status.

Each order should display:

Order ID
Order date
Items ordered
Quantity
Total amount
Delivery date
Order status
"View Details" button

Clicking "View Details" should open a detailed order page.

Delivery Details

For an active order, show:

Order ID
Customer name
Delivery address
Items
Quantity
Order total
Delivery date
Delivery time slot
Delivery status

Delivery person's contact number, if applicable

Add a simple delivery progress timeline:

Order Placed → Confirmed → Preparing → Out for Delivery → Delivered

Important Privacy Requirement

Customers must never be able to access another customer's:

Orders
Name
Phone number
Address
Delivery details
Payment information

Implement proper authentication and authorization so every customer can only access their own records.

Design

Use a professional drinking-water theme:

White background
Blue and light-blue primary colors
Clean cards
Rounded buttons
Simple icons
Large readable text
Mobile-first responsive layout
Fast-loading pages
Minimal animations

The website should feel trustworthy, clean, and hygienic.

Navigation

Customer navigation should contain only:

Home
Order Water
My Orders
Profile

Do not add unnecessary sections such as:

Product management
Customer management
Delivery management
Reports
Analytics
Staff management

Those features belong only in the separate admin dashboard.

Authentication

Implement:

Customer registration
Login

Secure session management

Name
Mobile number

Optional alternate contact number
Notifications

After an order is placed, show a confirmation notification.

When the order status changes, provide a notification to the customer.

Examples:

"Your order #1025 has been confirmed."

"Your order #1025 is out for delivery."

"Your order #1025 has been delivered."

Cash on Delivery

Key Business Rule

The customer-facing website should remain an ordering and order-tracking portal only.

The customer should not see or interact with the agency's internal business operations.

The final experience should be:

Login → Order Water → Place Order → View Order → Track Delivery → Receive Water

Make the UI extremely simple so that a customer can place an order in less than a few minutes, even if they are not technically experienced.
